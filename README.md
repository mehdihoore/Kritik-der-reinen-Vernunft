# واژه‌نامۀ سنجش خرد ناب
## آلمانی ـ انگلیسی ـ فرانسه ـ فارسی
### [نیز شامل اصطلاح‌ها و عبارت‌های لاتین و یونانی متن]
## این واژه نامه از کتاب ترجمه فارسی سنجش خرد ناب اثر ایمانوئل کانت ترجمه میر شمس الدین ادیب سلطانی استخراج شده. مؤسسه انتشارات امیرکبیر تهران، چاپ نخست: ۱۳۶۲ هجری خورشیدی، مطابق با ۱۹۸۳ میلادی

 فایل 
 <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/Glossary.html">Glossary.html</a> را دانلود کنید و به سادگی از صفحه قابل جستجو به صورت آفلاین استفاده کنید. 
## بر اساس همین فایل یک اسکیل هم برای استفاده جهت ترجمه متون فلسفی با استفاده از هوش مصنوعی کلودی آماده شده است که <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/kant-glossary.skill">اینجا </a> در دسترس است.
### همچنین جهت استفاده با هوش مصنوعی گوگل یعنی جمینی سه فایل آماده شده است که می‌توان به روش زیر از آنها استفاده کرد:
1. به <a href="https://gemini.google.com/">gemini.google.com</a>بروید، از منو گزینهٔ **Gems** → **New Gem** را بزنید.
2. متن داخل <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/gem-instructions.txt">`gem-instructions.txt`</a> را کپی کنید و در بخش **Instructions** بگذارید.
3. زیر بخش **Knowledge**، روی **Add files** بزنید و هر دو فایل <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/glossary.md">glossary.md</a> و <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/intro.md">intro.md</a> را آپلود کنید.
4. یک اسم بدهید (مثلاً «واژه‌نامهٔ کانت») و **Save** کنید.

بعد از آن هر بار که با آن Gem گفتگو کنید، جمینی به این دو فایل دسترسی دارد و طبق همان دستورالعمل، پیش از ترجمهٔ اصطلاح‌های فلسفی به فارسی، اول واژه‌نامه را چک می‌کند.

 نکته: ساخت Gem با Knowledge files (آپلود فایل) در جمینی جزو امکانات نسخهٔ Advanced/پولی است؛ اگر حساب رایگان دارید، این گزینه شاید در دسترس نباشد یا باید هر بار متن را دستی در گفتگو بچسبانید.

 #### همچنین برای استفاده از فایلها در گوگل ای‌آی استودیو به روش زیر عمل کنید:
 وارد <a href="https://aistudio.google.com/prompts/new_chat">aistudio.google.com</a> شوید، یک چت جدید (Chat mode) باز کنید.
پنل System instructions را باز کنید و متن <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/gem-instructions.txt">`gem-instructions.txt`</a> را در آن بچسبانید.
دو فایل <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/glossary.md">glossary.md</a> و <a href="https://github.com/mehdihoore/Kritik-der-reinen-Vernunft/blob/main/intro.md">intro.md</a>  را از همان جعبهٔ ورودی چت آپلود کنید.
با دکمهٔ ذخیره/Save prompt (یا مشابه آن در نسخهٔ فعلی رابط کاربری) این تنظیمات را برای استفاده‌های بعدی نگه دارید.
